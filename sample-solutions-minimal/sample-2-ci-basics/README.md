# 샘플 2: CI 파이프라인 기초 (minimal)

## 목적
최소 YAML 뼈대에서 GitHub Actions CI 워크플로우를 직접 완성합니다.

## 완료한 일
1. .github/workflows/ci.yml에 push, pull_request 트리거를 작성했습니다.
2. checkout, Python 설정, 의존성 설치, lint 단계를 추가했습니다.
3. 저장소 push 후 Actions 실행 결과 확인이 필요합니다.

## 제출 체크
- ci.yml 작성 완료
- Actions 실행 기록은 GitHub push 후 확인 필요
- 성공 로그는 Actions 실행 후 확인 필요
