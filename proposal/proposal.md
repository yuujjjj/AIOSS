# 프로젝트 제안서

## 프로젝트명
GovOn: 온프레미스 기반 AI 민원 처리 지원 시스템

## 문제 정의
공공기관 민원 업무는 민원 접수 이후 내용 분석, 담당 부서 분류, 과거 사례 탐색, 답변 초안 작성 등의 과정이 필요하다.

그러나 기존 민원처리 시스템은 단순 키워드 기반 검색이기 때문에 능률이 낮다.
민원을 처리하는 공무원이 거의 수작업으로 진행하기 때문이다. 

또한 민원 데이터에는 개인정보가 포함될 수 있어 외부 클라우드 기반 AI 서비스 활용에 보안 문제가 발생할 수 있다.

따라서 본 프로젝트는 폐쇄망 환경에서도 동작 가능한
온프레미스 AI 기반 민원 처리 지원 시스템을 개발하는 것을 목표로 한다.

## 핵심 기능

### 1. 민원 분석 및 자동 분류
LLM 기반 자연어 처리 기술을 활용하여
민원 내용을 분석하고 민원 유형을 자동으로 분류한다.

### 2. 유사 민원 사례 검색
벡터 검색을 통해 입력된 민원과 의미적으로 유사한
과거 민원 사례와 답변을 탐색한다.

### 3. 답변 초안 생성
민원 내용을 바탕으로 공공기관 형식에 맞는
답변 초안을 자동으로 생성한다.

## 기술 스택

- EXAONE-Deep-7.8B
- Supervised Fine-Tuning (QLoRA)
- vLLM
- AWQ Quantization 등등
